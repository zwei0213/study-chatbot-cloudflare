# 汉译英 AI 陪练网站：管理员使用说明

本文只介绍低温暖/高温暖汉译英陪练实验的管理方法。部署完成后，管理页面地址为：

**https://study.489646.xyz/manage/practice**

## 1. 登录

1. 打开上方管理页面。
2. 输入 Cloudflare Worker Secret `STUDY_ADMIN_TOKEN`，点击“登录陪练后台”。
3. 登录状态有效期为 8 小时；过期后重新登录即可。

如果尚未设置密钥，请在 Cloudflare Worker 的 **Settings → Variables and Secrets** 中添加 `STUDY_ADMIN_TOKEN`。密钥至少 32 个字符，保存后重新部署 Worker。

## 2. 浏览参与记录

登录后，页面左侧按创建时间倒序显示陪练记录。每条记录可查看：

- 实验组别：低温暖组或高温暖组。
- 当前阶段，以及已完成的必做题和加练题数量。
- 记录创建时间。
- 已完成者的 15 位完成编码；未完成者显示为未完成。

在页面顶部的“陪练配置”中，可以保存陪练专用的 DeepSeek API Key、选择 DeepSeek 模型，编辑共同提示词、低/高温暖提示词和欢迎语，并修改全部 25 道题的中文题目与参考译文。保存 API Key 后会加密写入 D1，不会在页面回显；后台配置优先于 Worker Secret `DEEPSEEK_API_KEY`。留空 Key 输入框表示保持当前设置。新建的会话应用最新配置，已开始的会话继续使用创建时保存的模型、提示词、欢迎语和题库快照。

点击一条记录，右侧会显示完整对话。每条消息会标出参与者或 AI、题号、正确/错误判定和时间。

## 3. 按完成编码查找

1. 在搜索框输入完成编码。可输入完整的 15 位编码，也可输入其中一段；字母不区分大小写。
2. 点击“查找”。
3. 点击结果即可查看对应的完整对话。
4. 点击“显示全部”返回所有记录。

尚未完成 5 道必做题的参与者不会获得完成编码，因此这类记录请从左侧记录列表中查找。

## 4. 删除记录

1. 先从列表或搜索结果中选中记录。
2. 在对话详情顶部点击“删除记录”。
3. 阅读确认提示后，点击“确认删除”。

删除会永久移除该参与者的会话和全部消息，无法在管理页面恢复。删除前请确认记录和编码正确。

## 5. 导出 CSV

点击“导出 CSV”可下载陪练实验记录表。导出内容包括所有陪练记录，不受当前编码搜索条件影响，包含组别、完成编码、进度、消息内容、判定结果和时间等字段。文件可能包含参与者的原始回答，请妥善保存并限制访问。

## 6. 参与者页面与完成编码

- 低温暖组：`https://study.489646.xyz/practice/low`
- 高温暖组：`https://study.489646.xyz/practice/high`

参与者完成 5 道必做题后，结束练习或拒绝继续加练时会收到完成编码。答题是否正确、是否参加加练，不影响编码发放。未完成 5 道必做题就退出，不会获得编码，但已提交的对话和进度仍会保存。

## 7. 模型 API Key

陪练默认使用 DeepSeek `deepseek-flash`。推荐在 `/manage/practice` 顶部的“陪练配置”中设置专用 API Key 和模型。也可以在 Cloudflare Worker 的 **Settings → Variables and Secrets** 中设置 `DEEPSEEK_API_KEY` 作为环境变量。

后台保存的陪练 API Key 优先于环境变量。清除后台 Key 后，如果设置了环境变量则自动回退使用；否则需重新设置 Key 才能调用模型。

保存到后台的 API Key 使用 `STUDY_ADMIN_TOKEN` 派生密钥加密。更换 `STUDY_ADMIN_TOKEN` 后，需重新保存 API Key。

## 8. 常见情况

- **密钥无效**：确认输入的是当前 Worker 的 `STUDY_ADMIN_TOKEN`，不是 DeepSeek API Key。
- **尚未设置管理密钥**：确认 Cloudflare Secret 名称准确、长度至少 32 个字符，并已部署生效。
- **没有记录或配置保存失败**：确认当前环境已部署陪练功能，并已执行 `0005_practice_settings.sql` 迁移。
- **提示模型请求失败**：检查 DeepSeek API Key 和 DeepSeek 账号状态；管理页面的 CSV 导出与对话浏览不需要模型请求。
